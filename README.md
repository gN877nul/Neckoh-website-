# Neckoh-website-

Este archivo HTML constituye la estructura principal (layout de navegación y footer) de la página de inicio para una plataforma web de eSports (NECKOH/NEXUS ESports). Proporciona navegación general, enlaces a páginas de videojuegos específicos, barra de búsqueda, links de navegación secundaria y pie de página informativo con enlaces a redes sociales y legales.

El encabezado está dividido en tres bloques principales dentro de un contenedor flexible (header-container):

A. Marca / Identotipo (.logo-container)
Icono: fa-gamepad (Mando de videojuegos).

Texto: NECKOH ESPORTS.

B. Menú de Navegación (.main-nav)
El menú principal utiliza una lista no ordenada (<ul class="nav-list">) con las siguientes secciones:

Inicio (index.html): Enlace activo a la página de inicio.

Juegos (Menú Desplegable .dropdown):

Valorant: recursos/valorant.html (Icono: Mirilla).

Fortnite: recursos/fortnite.html (Icono: Escudo).

SSBU (Super Smash Bros Ultimate): recursos/SuperSmash.html (Icono: Pistola).

Rocket League: recrusos/rocketL (Icono: Coche).

Torneos: Enlace directo a la sección de torneos.

Noticias: Enlace a artículos y noticias de eSports.

Equipos: Enlace a la sección de equipos de la plataforma.

C. Acciones del Encabezado (.header-actions)
Barra de Búsqueda (.search-box): Campo de texto (<input>) para buscar torneos o jugadores profesionales (pros).

Boton de Menú Hamburguesa (#menuToggle): Botón responsivo para desplegar el menú en dispositivos móviles.

Actualmente se encuentra vacío en la plantilla base. Esta etiqueta servirá como contenedor del contenido dinámico o principal de la página.

El footer se organiza en un contenedor multi-columna (footer-container) e incluye:
A. Columna 1: Marca e Información (.footer-brand)
Logo: Muestra la marca de la plataforma (NEXUS ESPORTS).

Descripción (.footer-bio): Breve resumen sobre el propósito de la plataforma.

Redes Sociales (.footer-socials): Enlaces a las comunidades oficiales:

Twitter / X (fa-x-twitter)

Twitch (fa-twitch)

YouTube (fa-youtube)

Discord (fa-discord)

B. Columnas de Enlaces
Navegación: Enlaces rápidos a Inicio, Torneos Activos, Calendario y Ranking Global.

Juegos: Enlaces rápidos a Smash Bros. Ultimate, Valorant, League of Legends y Counter-Strike 2.

Soporte y Legal: Enlaces a Centro de Ayuda, Términos de Servicio, Política de Privacidad y Contacto / Sponsors.

C. Barra Inferior (.footer-bottom)
Copyright: Muestra el aviso de derechos reservados (© 2026 NECKOH ESports).

Indicador de Estado (.status-indicator): Muestra visualmente el estado de la infraestructura (Servidores Operativos).
